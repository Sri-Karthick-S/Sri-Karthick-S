## Featured Projects

### Smart Grid Telemetry Data Pipeline and Forecasting
Python · TensorFlow · LSTM · Azure (in progress)

Engineered a robust time-series pipeline to audit, validate, and repair 2.54 million telemetry records from real-world smart grid systems. Developed a Bidirectional LSTM model with cyclical feature engineering, achieving an industrial-grade 9.88% MAPE - outperforming traditional linear baselines. Currently enhancing with Azure Data Lake and Synapse infrastructure for scalable production deployment.

`Status: In progress - Azure integration phase`

### Customer Shopping Behaviour Analysis Dashboard
Python · SQL · Power BI

Cleaned and transformed 3,900 retail transaction records and performed structured SQL analysis across 10 business queries covering customer segmentation, revenue trends, and discount dependency. Built an interactive Power BI dashboard designed for non-technical stakeholders to explore findings independently. Identified that 73% of customers were non-subscribers despite comparable average spend, informing potential subscription strategy improvements.

[![GitHub](https://img.shields.io/badge/GitHub-View_Repo-181717?style=flat&logo=github)](https://github.com/Sri-Karthick-S/customer-shopping-behavior-analysis)

### Music and Mental Health Analysis Dashboard
Python · R · Shiny · Statistical Analysis

Built an interactive R Shiny dashboard analysing 736 survey responses with dynamic filtering, designed so non-technical users could explore statistical findings without interpreting raw data. Identified a 28.4% gap between perceived and actual distress levels across respondents, surfacing a counterintuitive insight from survey data and communicating it visually.
